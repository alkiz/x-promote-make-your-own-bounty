Entry for make.fun's “Promote make.fun's make-your-own-bounty post on X” bounty ($250, top 50 share the prize): one post of our own on X quoting make.fun's make-your-own-bounty post, with a photo of its own attached and make.fun/@makefunai plus our play code in its text. This repository hands in the post's address in POST.json; main.ts copies it to /output for the gate. Places go by the post's replies + reposts + quotes at the deadline (2026-11-26T18:35:00Z).

Status: skeleton — POST.json still holds the placeholder address. Once the real post is up on X, its address goes into POST.json and the entry is submitted.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
